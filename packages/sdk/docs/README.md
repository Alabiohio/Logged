# Logged SDK documentation

This package includes the local documentation bundle that is installed alongside the SDK.

## Files

- `docs/README.md` — this documentation index
- `dist/` — bundled SDK runtime and types

## Install location

After `npm install`, the docs are available in:

```bash
node_modules/@oheoco/logged/docs
```
